# Official sources (copies)

Copies of official SUNAT documents used to specify Formats 12.1 / 14.1 and the SIRE reconciliation, so every rule
can be checked against the original. Origin URLs and SHA-256 hashes are listed in `docs/sunat/fuentes.md`.

| File | Used for |
|---|---|
| `SUNAT-Estructura-PLE-v5-Anexo2.xls` | Rules R-60 to R-66 and R-70 to R-75 (PLE file name, empty fields, field 5, field 35, 12.1 field 11) |
| `RS-112-2021-SUNAT-separata-El-Peruano.pdf` | Rule R-76 and ADR-007 (proposal fields, CAR, voided documents with 0.00, rejected number rendered void) |
